# PROCESSED RETURNS REPORT - UI & EXPORT GUIDE

## Overview

The **Processed Returns Report** is a summarized listing screen that displays completed property returns for landlords/clients. Users can:

1. View returns in a **summary table** (per landlord/property)
2. **Filter** by period, client, property, status
3. **Download PDF** - Formatted report with details
4. **Download Excel** - Data export for analysis
5. **Drill down** - Click on report to view full details

This document covers the database tables, query joins, UI columns, and export columns for implementation.

## 🔗 Database Query with Joins

### SQL Query for Returns Listing

```sql
SELECT
    -- Report details
    rp.id AS report_id,
    rp.date_time,
    rp.reference_number,
    rp.period_date,
    rp.batch_id,

    -- Period details
    period.period_name,
    period.period_date AS period_month,

    -- Client details
    c.id AS client_id,
    CONCAT_WS(' ', c.names, c.second_name, c.last_name) AS client_name,
    c.email AS client_email,
    c.phone AS client_phone,
    c.kra_pin AS client_kra_pin,

    -- Property details
    p.id AS property_id,
    CONCAT_WS(' - ', p.reference_number, p.property_name) AS property,
    p.reference_number AS property_code,
    p.property_name,
    p.location AS property_location,

    -- SLA details
    sla.reference_number AS sla_reference,
    sla.commission_rate,
    sla.vat_rate,

    -- Return type
    rt.type_name AS return_type,

    -- Financial details
    rp.total_gross_amount,
    rp.total_commissionable,
    rp.total_commission,
    rp.vat_on_commission,
    rp.total_vat,
    rp.total_recoveries,
    rp.total_net_amount,
    rp.properties_net,
    rp.other_transactions,
    rp.total_featured_items_amount,

    -- Status
    ws.status_name AS current_status,
    ws.id AS status_id,

    -- Field officer
    staff.names AS field_officer,

    -- Batch
    batch.reference_number AS batch_reference,

    -- Approval details
    rp.approved_by,
    rp.approval_date,
    rp.created_by

FROM sys_reports_returns_properties rp

-- Client join (REQUIRED)
INNER JOIN sys_pm_clients c
    ON c.id = rp.client_id

-- Property join (REQUIRED)
INNER JOIN sys_pm_properties p
    ON p.id = rp.property_id

-- Period join (REQUIRED)
LEFT JOIN sys_pm_clients_periods_closures period
    ON period.id = rp.period_id

-- Status join (REQUIRED)
LEFT JOIN sys_set_workflow_statuses ws
    ON ws.id = rp.current_status_id

-- Return type join
LEFT JOIN sys_pm_clients_returns_types rt
    ON rt.id = rp.return_type_id

-- SLA join
LEFT JOIN sys_pm_service_agreements sla
    ON sla.id = rp.sla_id

-- Field officer join
LEFT JOIN sys_staff staff
    ON staff.id = rp.field_officer_id

-- Batch join
LEFT JOIN sys_reports_returns_batches batch
    ON batch.id = rp.batch_id

-- Filter conditions (add WHERE clause as needed)
WHERE rp.current_status_id IN (5, 17)  -- Approved or Processed
  -- AND DATE_FORMAT(rp.period_date, '%Y-%m') = '2026-01'  -- Optional: Filter by period
  -- AND rp.client_id = 14  -- Optional: Filter by client
  -- AND rp.property_id = 501  -- Optional: Filter by property

ORDER BY rp.period_date DESC, c.names ASC, p.property_name ASC;
```

## 🎯 Sample Queries

### Get Returns for Client

```sql
SELECT
    rp.id,
    rp.reference_number,
    p.property_name,
    period.period_name,
    rp.total_net_amount,
    ws.status_name
FROM sys_reports_returns_properties rp
INNER JOIN sys_pm_clients c ON c.id = rp.client_id
INNER JOIN sys_pm_properties p ON p.id = rp.property_id
LEFT JOIN sys_pm_clients_periods_closures period ON period.id = rp.period_id
LEFT JOIN sys_set_workflow_statuses ws ON ws.id = rp.current_status_id
WHERE rp.client_id = 14
  AND rp.current_status_id = 17  -- Processed
ORDER BY rp.period_date DESC
LIMIT 10;
```

### Get Returns by Period

```sql
SELECT
    c.names AS client_name,
    COUNT(rp.id) AS returns_count,
    SUM(rp.total_gross_amount) AS total_gross,
    SUM(rp.total_commission) AS total_commission,
    SUM(rp.total_net_amount) AS total_net
FROM sys_reports_returns_properties rp
INNER JOIN sys_pm_clients c ON c.id = rp.client_id
WHERE DATE_FORMAT(rp.period_date, '%Y-%m') = '2026-01'
  AND rp.current_status_id = 17
GROUP BY c.id, c.names
ORDER BY total_net DESC;
```

### Get Top Properties by Returns

```sql
SELECT
    p.reference_number,
    p.property_name,
    c.names AS client_name,
    COUNT(rp.id) AS months_count,
    AVG(rp.total_net_amount) AS avg_monthly_return,
    SUM(rp.total_net_amount) AS total_returns
FROM sys_reports_returns_properties rp
INNER JOIN sys_pm_properties p ON p.id = rp.property_id
INNER JOIN sys_pm_clients c ON c.id = rp.client_id
WHERE rp.current_status_id = 17
  AND rp.period_date >= DATE_SUB(CURDATE(), INTERVAL 6 MONTH)
GROUP BY p.id, p.reference_number, p.property_name, c.names
ORDER BY total_returns DESC
LIMIT 10;
```
