# PAYMENTS TO INVOICES ALLOCATION - END-TO-END PROCESS

## 📋 Overview

This document provides a complete end-to-end explanation of how tenant payments are automatically allocated to invoices, how invoice balances are updated, how return thresholds are calculated, and how payability is determined in the CHIPS Property Management System.

---

## 🎯 High-Level Process Flow

```
┌─────────────────────────────────────────────────────────────────────┐
│                    PAYMENT TO INVOICE ALLOCATION                     │
│                         (Fully Automatic)                            │
└─────────────────────────────────────────────────────────────────────┘

STEP 1: Payment Received
│  - Tenant makes payment (Bank/Mpesa/Cash)
│  - Payment recorded in sys_pm_tenants_payments
│  - Status: Unallocated (11)
│  - Linked to lease_id
│
▼

STEP 2: Automatic Allocation Triggered
│  - TenantPaymentService::processPayments() runs
│  - Finds all unallocated payments
│  - For each payment → Find unsettled invoices by lease_id
│
▼

STEP 3: Invoice Matching & Sorting
│  - Get all invoices for payment->lease_id
│  - Include old lease invoices (if tenant moved)
│  - Include linked lease invoices (if multi-unit tenant)
│  - Sort by: Oldest first → Payment Priority → Date
│
▼

STEP 4: Allocation Loop
│  For each invoice (in sorted order):
│  ┌──────────────────────────────────────────────────────┐
│  │ a) Calculate remaining payment amount                │
│  │ b) Calculate invoice balance                         │
│  │ c) Determine allocation amount:                      │
│  │    - If payment = invoice balance → Full clear       │
│  │    - If payment < invoice balance → Partial clear    │
│  │    - If payment > invoice balance → Clear & continue │
│  │ d) Create allocation record                          │
│  │ e) Update invoice current_balance                    │
│  │ f) Update payment status                             │
│  └──────────────────────────────────────────────────────┘
│
▼

STEP 5: Return Threshold Update (PER ALLOCATION)
│  - ClientReturnService::updateReturnOnInvoicePayment() triggered
│  - Calculate threshold: (paid_so_far / total) × 100
│  - Check previous month threshold
│  - Determine payable_status_id:
│    * 0 = Unpayable (< 85% and prev month < 85%)
│    * 1 = Payable (= 100% or ≥ 85%)
│    * 2 = No Past Invoice
│    * 3 = Past Passed Threshold (prev ≥ 85%)
│  - Update sys_pm_clients_returns
│
▼

STEP 6: Final Status Update
│  - Invoice marked as Cleared (9) or Partially Cleared (8)
│  - Payment marked as Fully Allocated (13) or Partially Allocated (12)
│  - Return marked as Payable (1) or remains Unpayable (0)
│
▼

RESULT: Invoice Balance Reduced, Return Threshold Updated, Payability Determined
```

## 📊 Database Tables Involved

### Core Tables

#### 1. **`sys_pm_tenants_payments`** - Payment Records

**Purpose:** Stores all tenant payments received

| Column            | Type    | Description                                                |
| ----------------- | ------- | ---------------------------------------------------------- |
| id                | INT     | Primary key                                                |
| payment_date      | DATE    | Date payment received                                      |
| reference         | VARCHAR | Payment reference (bank ref, mpesa code)                   |
| receipt_number    | VARCHAR | System-generated receipt                                   |
| amount            | DECIMAL | Total payment amount                                       |
| lease_id          | INT     | Link to tenant's lease                                     |
| tenant_id         | INT     | Link to tenant                                             |
| unit_id           | INT     | Link to unit                                               |
| property_id       | INT     | Link to property                                           |
| client_id         | INT     | Link to landlord                                           |
| current_status_id | INT     | 11=Unallocated, 12=Partially Allocated, 13=Fully Allocated |
| channel_id        | INT     | Payment method (1=Equity, 2=Mpesa, 3=Coop)                 |
| narration         | TEXT    | Payment description                                        |

**Key Statuses:**

- `11` = Unallocated (has money available)
- `12` = Partially Allocated (some money left)
- `13` = Fully Allocated (all money used)

```
paid_so_far = total_amount - current_balance
threshold = (paid_so_far / total_amount) × 100
```

#### 4. **`sys_pm_clients_returns`** - Return Records

**Purpose:** Stores return records linked to invoices (what landlord receives)

| Column                   | Type    | Description                                                     |
| ------------------------ | ------- | --------------------------------------------------------------- |
| id                       | INT     | Primary key                                                     |
| invoice_id               | INT     | Foreign key → sys_pm_debtors_invoices                           |
| return_date              | DATE    | Return period (YYYY-MM-01)                                      |
| trans_amount             | DECIMAL | Invoice total amount                                            |
| comm_amount              | DECIMAL | Commission amount                                               |
| comm_vat                 | DECIMAL | VAT on commission                                               |
| payable_amount           | DECIMAL | Amount payable to landlord                                      |
| **threshold_percentage** | DECIMAL | **Payment threshold % (LIVE FIELD)**                            |
| **payable_status_id**    | INT     | **0=Unpayable, 1=Payable, 2=No Past, 3=Past≥85%, 17=Processed** |
| current_status_id        | INT     | Workflow status                                                 |
| lease_id                 | INT     | Link to lease                                                   |
| trans_type_id            | INT     | Item type (same as invoice item_type_id)                        |

**Payable Status Logic:**

- `0` = Unpayable: Threshold < 85% and previous month < 85%
- `1` = Payable: Fully paid (100%) OR current threshold ≥ 85%
- `2` = No Past Invoice: First invoice for this tenant+item
- `3` = Past Passed Threshold: Current < 85% but previous month ≥ 85% (STILL PAYABLE!)
- `17` = Processed: Payment made to landlord

## 🔄 Detailed Process Breakdown

### Phase 1: Payment Reception & Storage

**Function:** `TenantPaymentService::recordPayment()`

```php
public static function recordPayment($log_data, $tenant_posted_id = 1, $is_recovery = false, $is_suspense = false)
{
    $tenant_payment_dao = new TenantPaymentDao();

    // Check for duplicate reference
    if($tenant_payment_dao->getByRef($log_data->reference)) return false;

    // Build payment record
    $data = new stdClass();
    $data->date_time = date('Y-m-d H:i:s');
    $data->payment_date = $log_data->payment_date;
    $data->reference = $log_data->reference;  // Bank ref, Mpesa code
    $data->receipt_number = UtilityReferencesService::createTenantPaymentRef($log_data->channel_id);
    $data->amount = $log_data->amount;
    $data->lease_id = $log_data->lease_id;  // ← KEY MATCHING FIELD
    $data->tenant_id = $log_data->tenant_id;
    $data->unit_id = $log_data->unit_id;
    $data->property_id = $log_data->property_id;
    $data->client_id = $log_data->client_id;
    $data->current_status_id = 11;  // Unallocated
    $data->channel_id = $log_data->channel_id;
    $data->narration = $log_data->narration;

    // Save payment
    if($data->id = $tenant_payment_dao->persist($data)){
        // Create tenant ledger entry (credit tenant account)
        TenantTransService::createFromPayment($data, $tenant_posted_id);
        return $data->id;
    }
}
```

**Result:**

- Payment saved with `current_status_id = 11` (Unallocated)
- Tenant account credited in ledger
- Ready for automatic allocation

### Phase 2: Invoice Matching & Sorting

**Function:** `TenantPaymentService::processPayments()`

```php
public static function processPayments($unit_id = null, $client_id = null)
{
    // Get all unallocated/partially allocated payments
    $unallocated = true;
    $unallocated_payments = (new TenantPaymentDao())->getAll($unallocated, null, null, $unit_id, $client_id);

    $invoice_dao = new InvoiceDao();
    $generic_dao = new GenericDao();

    foreach($unallocated_payments as $payment){
        $unsettled = true;
        $debtor_type_id = 2;  // Tenants
        $lease_id = $payment->lease_id;

        // STEP 1: Check if tenant moved from another unit
        // Clear old lease invoices FIRST
        if($previous_lease = $generic_dao->getByColumn('sys_pm_movement_requests', 'new_lease_id', $lease_id)){
            $old_lease_id = $previous_lease->lease_id;
            if($invoices = $invoice_dao->getInvoicesByLease($old_lease_id, null, $debtor_type_id, $unsettled)){
                usort($invoices, 'self::sortInvoices');
                foreach($invoices as $invoice){
                    self::allocateInvoice($invoice, $payment);
                }
            }
        }

        // STEP 2: Get current lease invoices
        if($invoices = $invoice_dao->getInvoicesByLease($lease_id, null, $debtor_type_id, $unsettled)){
            usort($invoices, 'self::sortInvoices');
            foreach($invoices as $invoice){
                self::allocateInvoice($invoice, $payment);
            }
        }

        // STEP 3: Check linked leases (multi-unit tenants)
        $active = true;
        if($linked_leases = (new LeaseDao())->getAll('id', 'ASC', null, null, $active, null, null, null, null, $lease_id)){
            foreach($linked_leases as $linked_lease){
                if($invoices = $invoice_dao->getInvoicesByLease($linked_lease->id, null, $debtor_type_id, $unsettled)){
                    usort($invoices, 'self::sortInvoices');
                    foreach($invoices as $invoice){
                        self::allocateInvoice($invoice, $payment);
                    }
                }
            }
        }
    }

    return true;
}
```

**Invoice Sorting Priority:**

```php
public static function sortInvoices($invoice_a, $invoice_b)
{
    // Get month start dates
    $date1 = date('Y-m-1', strtotime($invoice_a->date_due));
    $date2 = date('Y-m-1', strtotime($invoice_b->date_due));

    // Priority Order:
    // 1. OLDEST MONTH FIRST (Jan before Feb)
    // 2. SAME MONTH → LOWER payment_priority FIRST (1 before 2)
    // 3. SAME PRIORITY → EARLIER DATE FIRST

    if(($date1 == $date2) && ($invoice_a->payment_priority == $invoice_b->payment_priority)){
        return strtotime($invoice_a->date_due) - strtotime($invoice_b->date_due);
    } else if($date1 == $date2){
        return $invoice_a->payment_priority - $invoice_b->payment_priority;
    } else {
        return strtotime($invoice_a->date_due) - strtotime($invoice_b->date_due);
    }
}
```

**Example Sort Result:**

```
Input Invoices:
- Feb 2026 Rent (priority=1)
- Jan 2026 Water (priority=2)
- Jan 2026 Rent (priority=1)
- Feb 2026 Water (priority=2)

After Sorting:
1. Jan 2026 Rent (priority=1) ← OLDEST + HIGHEST PRIORITY
2. Jan 2026 Water (priority=2)
3. Feb 2026 Rent (priority=1)
4. Feb 2026 Water (priority=2)
```

### Phase 3: Payment Allocation to Invoice

**Function:** `TenantPaymentService::allocateInvoice()`

```php
public static function allocateInvoice($invoice, $payment)
{
    $tenant_payment_invoice_dao = new TenantPaymentInvoiceDao();
    $invoice_dao = new InvoiceDao();
    $tenant_payment_dao = new TenantPaymentDao();

    // CALCULATE PAYMENT REMAINING BALANCE
    // Get sum of all previous allocations from this payment
    $payment_sum_allocations = $tenant_payment_invoice_dao->getElementSum($payment->id);
    $unallocated_amount = floatval($payment->amount - $payment_sum_allocations);

    // If no money left in payment, mark as fully allocated and exit
    $fully_allocated_id = 13;
    if(!($unallocated_amount > 0)){
        $params = array('id' => $payment->id);
        $values = array('current_status_id' => $fully_allocated_id);
        $tenant_payment_dao->updateVals($values, $params);
        return;
    }

    // CALCULATE INVOICE REMAINING BALANCE
    // Get sum of all allocations to this invoice
    $invoice_sum_allocations = $tenant_payment_invoice_dao->getElementSum(null, $invoice->id);
    $invoice_balance = floatval($invoice->total_amount - $invoice_sum_allocations);

    // DETERMINE ALLOCATION SCENARIO
    $invoice_cleared_id = 9;
    $allocate_amount = false;

    // SCENARIO 1: Payment EXACTLY matches invoice balance
    if($unallocated_amount == $invoice_balance){
        $allocate_amount = $invoice_balance;
        $invoice_status_id = $invoice_cleared_id;  // 9 = Cleared
        $payment_status_id = 13;  // Fully allocated
        $new_invoice_balance = 0;
        $new_unallocated_balance = 0;
    }

    // SCENARIO 2: Payment LESS THAN invoice balance (partial payment)
    else if($unallocated_amount < $invoice_balance){
        $allocate_amount = $unallocated_amount;  // Use ALL remaining payment
        $invoice_status_id = 8;  // Partially cleared
        $payment_status_id = 13;  // Fully allocated (payment exhausted)
        $new_invoice_balance = $invoice_balance - $unallocated_amount;
        $new_unallocated_balance = 0;  // Payment used up
    }

    // SCENARIO 3: Payment GREATER THAN invoice balance (excess payment)
    else if($unallocated_amount > $invoice_balance){
        $allocate_amount = $invoice_balance;  // Use only what's needed

        if($payment->recovery_type_id){
            $invoice_status_id = $payment->recovery_type_id;
        } else {
            $invoice_status_id = $invoice_cleared_id;  // 9 = Cleared
        }

        $payment_status_id = 12;  // Partially allocated (money left over)
        $new_invoice_balance = 0;
        $new_unallocated_balance = $unallocated_amount - $invoice_balance;  // Leftover money
    }

    // CREATE ALLOCATION RECORD
    if($allocate_amount > 0){
        $data = new stdClass();
        $data->date_time = date('Y-m-d H:i:s');
        $data->invoice_id = $invoice->id;
        $data->payment_id = $payment->id;
        $data->prev_unallocated_balance = $unallocated_amount;
        $data->invoice_amount = $invoice_balance;
        $data->amount_allocated = $allocate_amount;
        $data->new_unallocated_balance = $new_unallocated_balance;
        $data->new_invoice_balance = $new_invoice_balance;
        $data->trans_date_time = $payment->payment_date;
        $data->lease_id = $payment->lease_id;
        $data->tenant_id = $payment->tenant_id;
        $data->client_id = $payment->client_id;
        $data->property_id = $payment->property_id;
        $data->unit_id = $payment->unit_id;

        // Save allocation record
        if($data->id = $tenant_payment_invoice_dao->persist($data)){

            // UPDATE INVOICE BALANCE (CRITICAL!)
            $params = array('id' => $invoice->id);
            $values = array('current_balance' => $new_invoice_balance);
            $invoice_dao->updateVals($values, $params);

            // Special check: If invoice fully paid and client conditions met
            if(ValidateInvoiceService::checkIfPayableClient($invoice->id)){
                $values = array('current_status_id' => 62);  // Returns Cleared
                $invoice_dao->updateVals($values, $params);
            }

            // UPDATE PAYMENT STATUS
            $params = array('id' => $payment->id);
            $values = array('current_status_id' => $payment_status_id);
            $tenant_payment_dao->updateVals($values, $params);

            // UPDATE BILLING RECORDS (if any)
            $billing_dao = new BillingDao();
            $collected_amount = $invoice->total_amount - $new_invoice_balance;
            $params = array('invoice_id' => $invoice->id);
            $values = array(
                'current_status_id' => $invoice_status_id,
                'current_balance' => $new_invoice_balance,
                'collected_amount' => $collected_amount
            );
            $billing_dao->updateVals($values, $params);

            // ★★★ TRIGGER RETURN THRESHOLD UPDATE ★★★
            ClientReturnService::updateReturnOnInvoicePayment($invoice->id, $payment->id);

            // Handle deposits (if applicable)
            $item_type_id = $invoice->item_type_id ?? $invoice->item_id ?? null;
            if(in_array($item_type_id, ToolsService::getGlobalSettings()['deposit_items'])){
                $active_status_id = ToolsService::getGlobalSettings()['workflow_statuses']['active'];
                DepositService::createFromInvoice($invoice->id, $active_status_id);
            }

            // Update arrears table
            $defaulters_dao = new DefaulterDao();
            $params = array('invoice_id' => $invoice->id);
            $values = array('current_status_id' => $invoice_status_id);
            $defaulters_dao->updateVals($values, $params);
        }
    }
}
```

**Allocation Scenarios Summary:**

| Scenario        | Payment | Invoice | Allocated | Invoice After | Payment After | Invoice Status | Payment Status         |
| --------------- | ------- | ------- | --------- | ------------- | ------------- | -------------- | ---------------------- |
| Exact Match     | 50,000  | 50,000  | 50,000    | 0             | 0             | Cleared (9)    | Fully Allocated (13)   |
| Partial Payment | 30,000  | 50,000  | 30,000    | 20,000        | 0             | Partial (8)    | Fully Allocated (13)   |
| Excess Payment  | 70,000  | 50,000  | 50,000    | 0             | 20,000        | Cleared (9)    | Partial Allocated (12) |

### Phase 4: Return Threshold Update & Payability Determination

**Function:** `ClientReturnService::updateReturnOnInvoicePayment()`

```php
public static function updateReturnOnInvoicePayment($invoice_id, $allocated_payment_id)
{
    $client_return_dao = new ClientReturnDao();
    $invoice_dao = new InvoiceDao();
    $item_dao = new ItemDao();

    // Get invoice details
    if(!$invoice = $invoice_dao->getById($invoice_id)) return false;

    // Get return record for this invoice
    $params = array('invoice_id' => $invoice_id);
    if(!$return = $client_return_dao->getByParams($params)[0] ?? null) return false;

    // Get item configuration
    $item_details = $item_dao->getById($invoice->item_type_id);

    // ═══════════════════════════════════════════════════════════
    // CALCULATE THRESHOLD PERCENTAGE
    // ═══════════════════════════════════════════════════════════
    $invoice_amount = $invoice->total_amount;
    $threshold = 0;
    $payable_status_id = 0;  // Default: Unpayable

    // Calculate how much has been paid
    if($paid_so_far = ($invoice_amount - $invoice->current_balance)){
        $threshold = round(($paid_so_far * 100) / $invoice_amount, 2);
    }

    // ═══════════════════════════════════════════════════════════
    // RULE 1: INVOICE FULLY PAID → ALWAYS PAYABLE
    // ═══════════════════════════════════════════════════════════
    if($invoice->current_status_id == 9){  // Cleared
        $threshold = 100;
        $payable_status_id = 1;  // Fully Paid - Payable
    }

    // ═══════════════════════════════════════════════════════════
    // RULE 2: ADVANCE PAYMENT LOGIC (85% THRESHOLD)
    // ═══════════════════════════════════════════════════════════
    else if($item_details->advance_payable == 'Yes' && $payable_status_id == 0){
        $allowed_thresh = 85;  // Configurable

        // Check current month threshold
        if($threshold >= $allowed_thresh){
            $payable_status_id = 1;  // Current month passed threshold
        }
        // Check previous month threshold
        else {
            $pending_id = 1;
            $past_month = date('Y-m', strtotime('last month', strtotime($invoice->date_due)));

            // Get previous month return for SAME lease + SAME item
            if($past = $client_return_dao->getAll(
                $past_month,
                null,
                $invoice->lease_id,      // Same lease
                $item_details->id,       // Same item type
                $pending_id
            )){
                if($past[0]->threshold_percentage >= $allowed_thresh){
                    $payable_status_id = 3;  // Past Passed Threshold - PAYABLE!
                } else {
                    $payable_status_id = 0;  // Unpayable
                }
            } else {
                $payable_status_id = 2;  // No Past Invoice
            }
        }
    }

    // ═══════════════════════════════════════════════════════════
    // RULE 3: RECOVERY INVOICES → UNPAYABLE
    // ═══════════════════════════════════════════════════════════
    $recovery_statuses = array(37, 35, 36, 34);  // Paid Owner, Sat Deposit, Absconded, Paid Vacant
    if(in_array($invoice->current_status_id, $recovery_statuses)){
        $payable_status_id = 0;  // Unpayable
        $threshold = 100;

        // Create recovery record if return was already paid
        if($return->paid_status_id == 2){
            $recovery_data = new stdClass();
            $recovery_data->type_id = $invoice->current_status_id;
            $recovery_data->amount = $return->trans_amount;
            $recovery_data->offset_invoice_id = $invoice->id;
            $recovery_data->narration = 'Recovery for invoice ref ' . $invoice->reference_number;
            // ... save recovery
        }
    }

    // ═══════════════════════════════════════════════════════════
    // UPDATE RETURN RECORD
    // ═══════════════════════════════════════════════════════════
    $values = array(
        'threshold_percentage' => $threshold,
        'payable_status_id' => $payable_status_id
    );
    $params = array('invoice_id' => $invoice_id);
    $client_return_dao->updateVals($values, $params);

    return true;
}
```

**Payable Status Decision Tree:**

```
Invoice Cleared (status=9)?
├─ YES → payable_status_id = 1 (Fully Paid)
└─ NO → Check Item Configuration
         │
         Item allows advance_payable?
         ├─ NO → payable_status_id = 0 (Unpayable - must be 100%)
         └─ YES → Check Current Threshold
                  │
                  Current threshold ≥ 85%?
                  ├─ YES → payable_status_id = 1 (Payable)
                  └─ NO → Check Previous Month
                          │
                          Previous month return exists?
                          ├─ NO → payable_status_id = 2 (No Past Invoice)
                          └─ YES → Previous threshold ≥ 85%?
                                   ├─ YES → payable_status_id = 3 (Past Passed - PAYABLE!)
                                   └─ NO → payable_status_id = 0 (Unpayable)
```

## 📚 SQL Queries for Implementation

### Get Invoice Current Balance

```sql
SELECT
    i.id,
    i.reference_number,
    i.total_amount,
    i.current_balance,
    (i.total_amount - i.current_balance) as paid_so_far,
    ROUND(((i.total_amount - i.current_balance) / i.total_amount) * 100, 2) as threshold_percentage
FROM sys_pm_debtors_invoices i
WHERE i.id = ?;
```

### Get Payment Allocations

```sql
SELECT
    api.id,
    api.payment_id,
    api.invoice_id,
    api.amount_allocated,
    api.date_time,
    p.reference as payment_ref,
    i.reference_number as invoice_ref
FROM sys_pm_tenants_payments_invoices api
JOIN sys_pm_tenants_payments p ON api.payment_id = p.id
JOIN sys_pm_debtors_invoices i ON api.invoice_id = i.id
WHERE api.payment_id = ?
ORDER BY api.date_time;
```

### Get Unallocated Payments

```sql
SELECT
    p.*,
    (p.amount - COALESCE(SUM(api.amount_allocated), 0)) as unallocated_amount
FROM sys_pm_tenants_payments p
LEFT JOIN sys_pm_tenants_payments_invoices api ON p.id = api.payment_id
WHERE p.current_status_id IN (11, 12)  -- Unallocated or Partially Allocated
  AND p.lease_id = ?
GROUP BY p.id
HAVING unallocated_amount > 0;
```

### Get Unsettled Invoices by Lease

```sql
SELECT
    i.*,
    (i.total_amount - COALESCE(SUM(api.amount_allocated), 0)) as current_balance_calc
FROM sys_pm_debtors_invoices i
LEFT JOIN sys_pm_tenants_payments_invoices api ON i.id = api.invoice_id
WHERE i.lease_id = ?
  AND i.debtor_type_id = 2  -- Tenants
  AND i.current_balance > 0  -- Not fully paid
GROUP BY i.id
ORDER BY
    DATE_FORMAT(i.date_due, '%Y-%m-01'),  -- Month
    i.payment_priority,                    -- Priority
    i.date_due;                            -- Date
```

### Get Previous Month Return

```sql
SELECT
    cr.threshold_percentage,
    cr.payable_status_id
FROM sys_pm_clients_returns cr
WHERE cr.return_date = ?  -- Format: 'YYYY-MM-01'
  AND cr.lease_id = ?
  AND cr.trans_type_id = ?  -- Item type ID
  AND cr.current_status_id = 1  -- Pending
LIMIT 1;
```

### Calculate Return Threshold

```sql
UPDATE sys_pm_clients_returns cr
JOIN sys_pm_debtors_invoices i ON cr.invoice_id = i.id
SET
    cr.threshold_percentage = ROUND(
        ((i.total_amount - i.current_balance) / i.total_amount) * 100,
        2
    ),
    cr.payable_status_id = CASE
        WHEN i.current_balance = 0 THEN 1  -- Fully paid
        WHEN ((i.total_amount - i.current_balance) / i.total_amount) * 100 >= 85 THEN 1  -- ≥85%
        ELSE 0  -- Unpayable (check prev month separately)
    END
WHERE cr.invoice_id = ?;
```

## 🚨 Critical Considerations

### 1. **current_balance is LIVE**

- Never recalculate from scratch
- Always update incrementally on allocation
- Trust this field as source of truth

### 2. **Allocation is ATOMIC**

- One allocation record per payment-invoice pair
- Each allocation updates both payment and invoice
- Never skip the junction table record

### 3. **Threshold Updates are REAL-TIME**

- Every allocation triggers return update
- Threshold changes immediately affect payability
- Previous month check is separate query

### 4. **Payment Can Split Across Multiple Invoices**

- Loop continues until payment exhausted
- Each loop creates new allocation record
- Status changes per allocation

### 5. **Invoice Sorting is CRITICAL**

- Wrong order = wrong allocations
- Oldest invoices must clear first
- Priority affects same-month ordering

### 6. **Previous Month Logic is SEPARATE**

- Current threshold = this month payment %
- Payable status = depends on last month
- Each lease+item tracked independently

### 7. **Recovery Invoices Break the Rules**

- Always unpayable (status = 0)
- Even if 100% paid
- Create recovery record for landlord
